# Сварные швы N1…N5 — расшифровка для защиты ПР3

**Источник:** `L3/Практика 3.pdf`, `L3/Шпора.docx`
**Стандарт:** ГОСТ 14771-76 (сварка в защитных газах), ГОСТ 5264-80 (ручная дуговая), ГОСТ 2.312 (обозначения на чертежах)

---

## Что такое N1…N5

`N1`…`N5` — **номера сварных швов**, ссылка с чертежа на строку Таблицы 1.

**Принцип:** чтобы не загромождать СБ повторяющимся обозначением, **полное обозначение шва** (тип + катет) выносится в **Таблицу 1**, а на чертеже у каждого шва ставится только **короткий номер** (`N1`, `N2`…).

---

## Таблица 1 (Балка `2А.012.001 СБ`)

| Номер | Обозначение | Длина, м | Расшифровка |
|-------|-------------|----------|-------------|
| `N1` | `Т3-Δ5` | 0,2 | Тавровое, тип 3, катет 5 мм |
| `N2` | `Н1-Δ5` | 1,96 | Нахлёсточное, тип 1, катет 5 мм |
| `N3` | `Т1-Δ5` | 2,5 | Тавровое, тип 1, катет 5 мм |
| `N4` | См. вид Е | 1,5 | Особый шов (показан на виде Е) |
| `N5` | `Т1-Δ3` | 0,18 | Тавровое, тип 1, катет 3 мм |

**Длина** = суммарная длина **всех швов этого номера** в изделии (не одного шва, а итого по сборке).

У `2А.012.002 СБ Подставка 1` своя Таблица 1 (N1, N2, N3), у `2А.012.003 СБ Подставка 2` — своя (N1, N2). Содержимое таблицы относится только к своему чертежу.

## Типы соединений (ГОСТ 14771-76 / 5264-80)

| Тип | Полное название | Что значит |
|-----|-----------------|------------|
| **Т1** | Тавровое односторонний | Без скоса кромок. Самый простой Т-стык, один проход. |
| **Т3** | Тавровое двусторонний | Без скоса. Два прохода с двух сторон, прочнее Т1. Толщина 2-40 мм. |
| **Т6** | Тавровое двусторонний со скосом одной кромки | Для толстого металла, обеспечивает проплавление. |
| **Н1** | Нахлёсточное односторонний | Без скоса. Один лист на другом. |
| **С1…С25** | Стыковое | Соединение по торцу. |
| **У1…У10** | Угловое | Под углом. |

**Δ** = угловой шов, число после = **катет** в мм.

**Расшифровка обозначения `Т1-Δ5`:**
- `Т1` — тавровое соединение, тип 1
- `Δ` — угловой шов
- `5` — катет 5 мм

## Расшифровка выносок на чертеже

### 1. Кружок `○ N1` (без полки)

- Кружок диаметром 6-8 мм с номером шва внутри.
- Означает: **шов сплошной, по умолчанию** — характеристики берутся из Таблицы 1.
- Линия-выноска заканчивается **точкой** (на поверхности) или **стрелкой** (на кромке).

### 2. `N1-⊐` (полка с прямоугольным значком)

- Полка-выноска со знаком шва.
- Значок **`⊐`** (открытый прямоугольник) = **прерывистый шов** (ГОСТ 2.312).
- Полная запись прерывистого шва: `N1 — l/t` где `l` — длина участка, `t` — шаг.
- Это **шахматный или цепной** прерывистый шов (по символу определяется ориентация участков).

### 3. Положение обозначения

- **Над полкой** — шов с **лицевой** стороны (видимый на чертеже).
- **Под полкой** — шов с **обратной** стороны (невидимый).

---

## Как читать выноску на СБ

1. Видишь `N3` в кружке → идёшь в **Таблицу 1** → находишь строку N3 → читаешь обозначение `Т1-Δ5` → ясно: тавровое, односторонний, катет 5 мм.
2. Видишь `N1-⊐` → берёшь из таблицы тип `Т3-Δ5`, **+ прерывистый** (значок `⊐`).
3. Если возле выноски стоит цифра (например `N1×4`) — количество таких швов.

---

## Зачем такая система

| Преимущество | Что даёт |
|--------------|----------|
| **Экономия места** на СБ | Не пишется `Т1-Δ5` у каждого из 20 швов |
| **Унификация** | Все швы одного типа гарантированно одинаковые (одна строка в таблице) |
| **Контроль** | ТТ п.3 «100% N1-N5 визуальный осмотр» — нумерация связывает швы с программой контроля |
| **Расчёт расхода** | Длина в метрах из таблицы → расход проволоки и защитного газа |

Нумерация **N1…N5** в таблице напрямую связана с ТТ — контролируется каждый шов по своему номеру.

## Формулировка для защиты

> «Номера `N1`-`N5` на чертеже — ссылки на Таблицу 1, где приведены полные обозначения швов по ГОСТ 14771-76 и суммарная длина каждого типа шва в метрах. Такая запись допускается ГОСТ 2.312 для сокращения чертежа при большом количестве швов одного типа. Например, `N1` соответствует тавровому двустороннему шву `Т3-Δ5` с катетом 5 мм, общая длина в изделии 0,2 м. Все швы N1-N5 подлежат 100% визуальному контролю с приёмкой по ГОСТ EN ISO 5817, уровень качества D/C.»

## Возможные вопросы

**В: Почему нельзя написать обозначение шва прямо у выноски?**
О: Можно, но при большом числе швов чертёж становится перегружен. ГОСТ 2.312 допускает выносить характеристики в таблицу при наличии трёх и более швов одного типа.

**В: Что обозначает значок `⊐` рядом с номером?**
О: Прерывистый шов (с интервалами). По ГОСТ 2.312 — открытый прямоугольник = шахматное или цепное расположение участков шва.

**В: Чем Т1 отличается от Т3?**
О: **Т1** — односторонний шов (катет с одной стороны), **Т3** — двусторонний (с двух сторон). Т3 прочнее, но требует два прохода и доступ с двух сторон.

**В: Что такое катет шва `Δ5`?**
О: Катет углового шва — расстояние от линии стыка до края шва в сечении. Δ5 = 5 мм. Определяет прочность шва.

**В: Длина 2,5 м для одного шва?**
О: Нет. **Суммарная** длина всех швов с номером N3 в изделии. Если шов N3 встречается 5 раз по 0,5 м — итого 2,5 м.

**В: Что такое `См. вид Е` у N4?**
О: Шов N4 имеет нестандартную форму (например, по сложному контуру) → его не получится записать одним обозначением, поэтому он подробно показан на отдельном виде `Е` чертежа.
