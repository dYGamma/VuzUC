## Советы по скриншотам

- Фон белый: `Tools → Options → System Options → Colors → Viewport Background → Plain`
- Только 3D-вид без UI-панелей SolidWorks
- `Ctrl+7` → стандартная изометрия
- Модель заполняет ~80% кадра
- Для деталей с фасками: повернуть так чтобы фаски были видны
- Рис.17 (Накладка 006): открыть конфигурацию по умолчанию, не -10/-20/-30
